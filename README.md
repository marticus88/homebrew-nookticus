# homebrew-nookticus

Homebrew tap for [Nookticus](https://nookticus.netlify.app/), a Dynamic Island clone for the Mac notch.

## Install

```
brew tap marticus88/nookticus
brew install --cask nookticus
```

The app is ad-hoc signed (no Apple Developer ID yet), so on first launch macOS may
require right-click → Open, or Settings → Privacy & Security → Open Anyway.
